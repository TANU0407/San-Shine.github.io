SANSHINE E-commerce Website
===========================

Files:
- index.html: Home page
- shop.html: Product shop with category filters
- about.html: About page
- contact.html: Contact form (opens WhatsApp)
- order.html: Order form (opens WhatsApp)
- style.css: Responsive CSS
- script.js: Product data, modal, size/color choices, order messages
- assets/images/: Uploaded product photos

How to run:
1. Extract the ZIP.
2. Keep the HTML, CSS, JS and assets folder together.
3. Open index.html in a browser. Bootstrap 5.3.3 is loaded from jsDelivr, so an internet connection is needed for Bootstrap styling.
4. For deployment, upload the whole folder to your web host.

Prices:
- Men's shirts: ₹300 each
- Ladies' purses: ₹200 each
Shirt sizes: L, XL, XXL, XXXL. Purses have no size field.

Orders:
The order/contact forms open WhatsApp at 70569 54262 with the details prefilled. Customers must review and press Send in WhatsApp. This is a front-end demo; it does not save orders to a database or take online payments.
